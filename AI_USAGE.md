# AI Usage

AI tools were used throughout the development of this project for planning, implementation, testing, debugging, and documentation.

## Tools Used

### Claude (Anthropic)

Claude was used during the initial development of the project.

It was used to:

- Plan the project architecture
- Understand the requirements of the assignment
- Inspect and reason about the scraping targets
- Build the scrapers and processing pipeline
- Implement cleaning, validation, and deduplication
- Create the test suite
- Prepare the README and project documentation
- Debug and improve the implementation

### ChatGPT (OpenAI)

ChatGPT was used during the review and refinement of the project.

It was used to:

- Review the implementation against the assignment
- Review individual files and improve code quality
- Identify unnecessary code and imports
- Check error handling and logging
- Review tests and edge cases
- Refine the final project structure
- Help prepare the project for submission and interview discussion

## Representative Prompt

The main development prompt was:

> `Review this project as a senior Python engineer. Check the implementation against the assignment requirements, identify anything unnecessary or incorrect, remove unnecessary code and imports, and keep the solution clean and interview-ready. `

Additional prompts were used to review, debug, test, and improve the implementation during development.

## AI-Assisted Areas

AI assistance was used across most parts of the project, including:

- Scrapers
- Data model
- Cleaning
- Validation
- Deduplication
- Consolidation
- HTTP client
- Logging
- Main pipeline
- Tests
- README
- Documentation

The final implementation was reviewed and tested after generation, and changes were made where necessary.

## Verification

The project was tested using the implemented test suite and offline fixtures.

The pipeline was also checked end-to-end to verify:

- Scraping flow
- Cleaning
- Validation
- Deduplication
- Consolidation
- CSV output
- Summary report generation
- Error handling

AI was used as a development and review tool. Responsibility for the final implementation and understanding of the code remains with the candidate.
